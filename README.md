  * 근태 관리, 전자결재, 메일, 시스템 관리, 채팅 등 업무 도메인 기능 구현
* Electron 기반 데스크톱 채팅 클라이언트의 사용자 흐름과 기능을 개선했습니다.

* Socket.IO, MongoDB 기반 실시간 채팅 기능과 Electron 배포 환경을 다뤘습니다.
* 기능 명세, 단위 테스트 시나리오, 시퀀스 다이어그램 등을 작성하며 개발 품질과 협업 효율을 높였습니다.
